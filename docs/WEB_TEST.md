# Проверка в браузере без kiosk

Нужен работающий backend из этой сборки. Опубликованные Sites — исходные прототипы, они не заменяют серверную тестовую систему. Cloud onboarding не публикует localhost/8443 наружу; внешний адрес появляется только после установки на доступный пользователю сервер или локальный компьютер.

## Вход и страницы

1. На выбранном сервере запустить сборку по INSTALL.md. Использовать отдельную TEST БД, проверяемый HTTPS и персональный пароль администратора. Не переносить в этот тест реальные ставки или рабочую CMS.
2. Открыть `/admin`. Зарегистрировать отдельные столы «Тест Poker» (Progressive Poker) и «Тест Baccarat» (Baccarat MAX).
3. Для каждого стола нажать «Выдать код привязки», затем «Тест в браузере». В открывшейся странице ввести соответствующий код и уникальное имя браузера. Код одноразовый, действует 10 минут. Не открывать второй операторский браузер того же стола одновременно.
4. В углу страницы нажать «ТЕСТ · кнопки». Адрес содержит `?test_controls=1`; кнопки существуют только при environment=test. Обычный kiosk URL не показывает панель. В диалоге панель переносится внутрь окна, чтобы можно было выбирать цифры и Enter мышью.

Панель имитирует клавиши и проходит через те же команды/авторизацию/lease/idempotency, что клавиатура. Самостоятельного финансового движка в ней нет. При offline операция не принимается. Настоящий NumPad для этой проверки не нужен; верхний цифровой ряд/Enter также поддерживаются в Progressive.

## Короткий сценарий Poker

- Нажать 1, 3 и Enter: подтверждаются два бокса, общая ставка 10 000 TZS. Фонды увеличиваются на 440/260/140/90/70 TZS (Royal → Flush); отчётный пул вне джекпотов — на 9 000.
- Нажать 0: раунд закрывается, фонды сохраняются.
- Новый раунд: 1, 2, Enter. Нажать * → 1, 2 → Enter → 1 (Flush) → Enter → 2 (7 карт) → Enter → Enter. Оба бокса имеют отдельные фиксированные выигрыши по 25 000; объявления в общей очереди. На одном боксе нельзя оформить вторую выплату.
- Для верхней категории выбрать 3/4/5; подтверждение требует персональный PIT или Admin. Для первых 5 карт сумма — текущий фонд (seed + накопленные отчисления), для 7 карт — фиксированная таблица.
- Для проверки общей синхронизации открыть другой тестовый стол в отдельной вкладке. Pending первого стола не мешает второму подтвердить ставки.

## Baccarat

Открыть отдельный Baccarat стол; панель передаёт клавиши именно Baccarat. 1 Player, 2 Banker, 3 Tie; 4/5 pair flags; 6–9/+ специальные результаты; Decimal отмена, 0 новая shoe с подтверждением. Подождать серверного подтверждения каждого результата. Перезагрузить страницу: статистика и shoe сохраняются. Администратор может изменить minimum/maximum через table_update: следующие руки получают новые лимиты, предыдущие сохраняют свои snapshots. F4 переключает представление; на отдельном Baccarat столе ставки Progressive запрещены.

## Отчёты

В `/admin` выбрать business day либо диапазон дней/месяц и при необходимости table_id. Проверить gross/net число ставок, пять фондов, отдельный non-jackpot pool, утверждённые/выданные выплаты и Baccarat recorded/undone/net. День начинается в 07:00 EAT. Все данные этого сценария тестовые.
