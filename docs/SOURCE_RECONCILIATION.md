## Получено из публичных Sites

Оба сайта доступны через HTTPS. Публичные HTML, JS, CSS сохранены отдельно в `docs/sources/published`; дата загрузки 8 октября 2026. Это опубликованные ресурсы, а не полный исходный checkout Sites или история редакций.

Progressive: сохранены опубликованная структура, логотип, карточные изображения, пять шрифтов, два фоновых изображения и пять вариантов оформления. Локальные финансовый движок и browser ledger из оригинала **не исполняются** в серверном терминале. Значения фондов, раунд, заявления и объявления поступают исключительно с сервера.

Baccarat MAX: подключены опубликованные engine.js/max.js/max.css, логотип, dragon/panda/tiger, галерея, 11 MP4 (исходные H.264 1280×720) и 11 JPEG. JS/CSS галереи вынесены во внешние файлы для CSP. Внесены только kiosk bridge, привязка локальной истории к table_id, серверные имя/лимиты стола и скрытие постоянных служебных кнопок. Игровые дороги рассчитывает оригинальный Baccarat engine. Никакой передачи Baccarat результатов в финансовый Progressive API нет.

F4 меняет только серверное поле представления; фонд, раунд и выбранные боксы сохраняются. Результаты Baccarat вводятся в iframe, клавиши Progressive там не обрабатываются. F4 из iframe передаётся оболочке после проверки origin, source и table_id. Общий выигрыш показывается поверх обоих режимов; после него остаётся прежний режим. Ввод Baccarat в оболочке блокируется при потере связи/операторской аренды и на время jackpot overlay. История Baccarat остаётся локальной, изолированной по table_id; это не серверная синхронизация.

## Что остаётся решением владельца

Досье явно не утверждает одновременные выигрыши, момент фиксации суммы, полную матрицу полномочий, House Rules, источники seed/top-up и назначение 4 500 TZS вне фондов. Также неоднозначна окончательная последовательность NumPad заявления; текущая раскладка остаётся тестовой. Эти пункты не превращены в якобы согласованные правила.

Существующая CMS — необязательная интеграция. Её отсутствие не блокирует самостоятельную разработку. Оборудование имеется; фактическая проверка и уточнение модели контроллера отложены пользователем.

SHA256 публичных исходников, предоставленных файлов и установленного Baccarat bundle записаны в `docs/sources/SHA256.json`.

Обновление после прямого ответа владельца: OWNER_DECISIONS.md заменяет прежние открытые вопросы о sequential/pending/PIT/NumPad.
