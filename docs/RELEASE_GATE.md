# Допуск к реальным ставкам закрыт

## Источники и интеграции

- Получены предоставленное досье/архив и публичные опубликованные HTML/JS/CSS/графика обоих Sites. Дизайн Progressive подключён к серверу; настоящий Baccarat MAX работает через F4 с отдельным вводом. Галерея и все 11 MP4 сохранены локально. Полный Sites checkout и история редакций не предоставлены. См. SOURCE_RECONCILIATION.md.
- Рабочая CMS не менялась. API v1/read/metadata adapter проверены как предлагаемый контракт. Реальный CMS API необходим только при подключении этой необязательной интеграции.
- История Baccarat теперь серверная по table_id, с архивами shoes, версиями лимитов и journal/undo. Ручной Baccarat display не является системой приёма/settlement денежных ставок Baccarat.

## Открытые финансовые правила

Владелец утвердил последовательные выплаты, фиксацию суммы при подтверждении, PIT либо Admin для верхних категорий, паузу только собственного стола, несколько победивших боксов и старшую комбинацию на бокс. Раскладка NumPad подтверждена; 90% ставки учитываются отдельным отчётным пулом. Эти решения реализованы и проверены.

Уточнение получено: FIRST FIVE — стартовая сумма плюс накопленные отчисления текущего фонда, SEVEN CARDS — фиксированная сумма. Неоднозначность типа выплаты снята; реализация совпадает с правилом. Источник покрытия seed/top-up из отчётного пула отдельно не указан; автоматического дебета этого пула нет. Требования, не утверждённые владельцем (детали poker House Rules, production credentials/домен), не выдаются за согласованные.

## Отложенные и площадочные проверки

- Оборудование Linux kiosk имеется; пользователь отложил аппаратные испытания. USB NumPad, controller firmware/protocol, focus/reboot/power-loss и display manager в облаке не проверены.
- Проверены две независимые browser contexts и 20 SSE subscribers. Это короткая облачная проверка, не 20 физических терминалов или длительный soak test.
- Перед эксплуатацией нужны персональные credentials, off-host backup/restore rehearsal, NTP, UPS, мониторинг, доступ DBA/Docker и оценка роста JSONB history.

Browser test balances не импортируются. Исходный локальный Progressive движок не исполняется. `production_released` всегда false; все установки TEST. Боевой запуск не заявляется.
