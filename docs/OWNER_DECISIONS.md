# Решения владельца — 8 октября 2026

Источник: прямой ответ пользователя в текущем чате. Это заменяет предположения из технического досье там, где решение однозначно.

1. Одновременные выигрыши оплачиваются последовательно. Порядок обработки — серверная транзакция подтверждения, не часы kiosk.
2. Сумма определяется при подтверждении PIT/Admin. Для категорий дилера подтверждение регистрации служит точкой обработки; сумма не фиксируется в момент создания заявки.
3. Flush/Full House подтверждает дилер; Four/Straight/Royal — PIT либо Admin. Уточнение владельца: FIRST FIVE — стартовая сумма плюс накопленные отчисления текущего фонда; SEVEN CARDS — только фиксированная сумма из таблицы. Все выплаты журналируются.
4. При pending/disputed блокируется только стол с заявкой. Остальные столы могут продолжать принимать ставки.
5. На столе возможны несколько выигрышных категорий и несколько победивших боксов. Для одного бокса оплачивается только старшая комбинация. Ввод должен явно перечислять выигравшие боксы; пять/семь карт остаются отдельными признаками.
6. Часть ставки вне пяти джекпотов учитывается отдельным отчётным пулом. Нужны число ставок и суммы по игровому дню, столу, казино. Не считать это автоматическим разрешением списывать seed/top-up из этого пула: источник финансирования отдельно не указан.
7. NumPad: * → боксы → комбинация (1 Flush … 5 Royal) → тип → Enter подтверждение.
8. Baccarat — отдельные столы; у каждого собственная статистика и изменяемые во времени лимиты/ставки. Выбор хранения пользователь доверил разработчику. Выбран серверный источник истории/версий настроек, чтобы восстановление kiosk не теряло данные и изменения не переписывали прошлое. Точное фактическое денежное принятие ставок Baccarat не путать с параметрами min/max существующего ручного display.

Правило обоих типов выплат подтверждено владельцем и совпадает с реализованным расчётом. Текущее состояние проверок — TEST_RESULTS.md.
