Every operation has an event ID, session, table, box list, round, UTC timestamp, EAT business date, before/after meters and financial breakdown. JSON contains the complete ledger and reconciliation; CSV is a flat event summary.

Business date changes at 07:00 EAT. Browser events are available through premier:progressive:event and window.PremierProgressive.subscribe(). No events are sent to a server. Different computers do not share balances in this version.

For reliable same-browser multi-window tests, serve this same HTML at localhost using the included launcher. Changing file path, hostname, port or browser profile creates a separate test ledger. Export before moving it.
